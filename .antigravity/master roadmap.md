🗺️ Master Roadmap: School Match Platform

학교와 검증된 인력을 잇는 신뢰 기반 매칭 플랫폼 (Educational HR Matching Service)

Vision: "선생님은 수업만 하세요. 인력 채용과 행정은 우리가 해결합니다."
Core Value:

Trust: 리뷰 기반의 검증된 인력 풀 (개인: 키워드 리뷰 / 업체: 별점)

Efficiency: 모바일로 끝내는 구인구직 & S2B 행정 연계

Safety: 학교 현장에 맞는 안전한 채용 프로세스 (개인정보 보호 & 검증)

🛤️ Phase Summary (Development Roadmap)

✅ Part 1: Foundation & Auth (Ready to Start)

목표: 서비스의 뼈대 구축 및 사용자 구분(학교/강사) 가입

핵심 기능:

Next.js + NestJS 모노레포 환경 구축

PostgreSQL + Prisma DB 설계 (회원 상태 관리 필드 포함)

JWT 기반 인증 (학교 관리자 vs 강사/업체 구분)

모바일 반응형 UI 기초 공사

🔜 Part 2: Supply Side (프로필 & 포트폴리오)

목표: "매력적이고 신뢰할 수 있는 인력 풀" 구축

정책 반영 (Q1-B): 가입은 자유, '지원' 또는 '프로필 공개' 시점에 인증 강제

핵심 기능:

강사 프로필: 사진, 자기소개, 활동 지역, 태그(#방과후 #돌봄)

미인증 태그: 자격 서류 미제출 시 '미인증' 라벨 크게 표시

자격 증명(Verification): 자격증, 성범죄 경력 조회 동의 여부, 사업자등록증 업로드

포트폴리오 업로드: 수업 활동 사진, 커리큘럼 파일

🔜 Part 3: Demand Side (공고 & 검색)

목표: 학교가 원하는 인력을 쉽고 빠르게 찾기

핵심 기능:

공고 올리기: "2학기 방과후 드론 강사 구합니다" (간편 입력 폼)

검색/필터: 지역별, 과목별, 날짜별 인력 검색

맞춤 추천: 우리 학교 근처의 '드론' 강사 자동 추천 목록

관심 등록: 찜하기(Scrap) 기능

🔜 Part 4: Matching & Communication (지원 & 소통)

목표: 연결을 성사시키고 조율하기 (Privacy First)

정책 반영 (Q2-B): 매칭 확정 전까지 연락처 비공개 (안심번호/채팅)

핵심 기능:

원클릭 지원: 인증된 강사만 지원 가능

제안하기: 학교가 강사에게 제안 (수락 시 채팅방 열림)

안심 채팅: 플랫폼 내 채팅으로 일정 조율 (개인정보 보호)

상태 관리: 지원 → 면접 요청 → 채용 확정(이때 연락처 상호 공개) → 거절

🔜 Part 5: Trust System (평가 & 리뷰)

목표: "검증된 데이터" 쌓기 (부장님 아이디어 핵심 반영)

핵심 기능:

개인 강사 리뷰: "키워드 선택형 리뷰" (예: ⏰시간약속 철저, 😊아이들과 친화적) - 별점 미사용

업체 리뷰: 별점 + 상세 후기 허용

재매칭 의사: "이 선생님과 다시 일하시겠습니까?" (Yes/No) 지수화

Badges: '인증된 강사', 'S2B 등록 업체' 배지

🔜 Part 6: Admin Efficiency (행정 & S2B 연계)

목표: 행정실 업무를 덜어주는 "문서 자동화"

핵심 기능:

서류 자동 생성: 채용 확정 시 '채용 계약서', '성범죄 조회 동의서' PDF 자동 생성

S2B 브릿지: "이 업체는 S2B에 등록된 업체입니다" 정보 연동

행정 대시보드: 이번 학기 채용 현황 대시보드

🏗️ Technical Strategy

| 영역 | 전략 | 이유 |
| Mobile | PWA + Responsive Web | 앱 설치 없이 접근성 극대화, 모바일/PC 통합 대응 |
| DB | PostgreSQL | 복잡한 관계형 데이터(매칭, 리뷰) 및 안정성 |
| Chat | Socket.io | 실시간 소통 및 알림 (매칭 성사 시 푸시) |
| Infra | Docker + AWS/Vercel | 확장성 및 유지보수 용이성 |

✅ Decided Policies (User Approved)

자격 증명 시점: (B) 활동 시 인증

전략: 초기 진입 장벽을 낮추되, 실제 매칭 시점에는 강력한 신뢰 검증 수행. 미인증 시 '지원 불가' 및 '프로필 미노출'.

연락처 공개 시점: (B) 매칭 후 공개

전략: 플랫폼 이탈 방지 및 교사/강사 개인정보 보호. 채팅을 통해 충분히 조율 후 상호 동의 하에 공개.
